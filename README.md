# Vian World

**Series:** Viabhron  
**Creator:** Lewis  
**Package:** `shura.el.viabhronicat`

Made on a low-end phone using Google AI Studio, GitHub and ChatGPT, with a little Claude along the way.

## Features

- **Launcher** — adapted from [Fossify Launcher](https://github.com/FossifyOrg/Launcher).
- **Firewall** — adapted from [TrackerControl for Android](https://github.com/TrackerControl/tracker-control-android).
- **Sidebar** — built with Google AI Studio, Claude and ChatGPT.

GitHub is used mainly to build the APK.
